# 🎬 Netflix Clone (HTML, CSS, JS)

A Netflix-inspired streaming website built entirely with **HTML, CSS, and JavaScript**.  
This project replicates the Netflix landing page experience, showcasing responsive design, interactive UI, and clean front-end development practices without using frameworks.

---

## 🚀 Features
- Responsive Netflix-style landing page
- Hero section with background image and call-to-action
- Navigation bar with language and sign-in buttons
- Email input field with "Get Started" button
- Multiple content sections:
  - Watch on TV
  - Download shows to watch offline
  - Stream everywhere
  - Create profiles for kids
- FAQ section with hover effects
- Footer with useful links
- Mobile-friendly layout with media queries

---

## 🛠️ Tech Stack
- **HTML5** – Structure and semantic elements  
- **CSS3** – Styling, layout, responsiveness, animations  
- **JavaScript (Vanilla)** – Interactivity and dynamic behavior
